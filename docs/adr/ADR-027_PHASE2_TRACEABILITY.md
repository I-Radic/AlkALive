## Legend

- **Impl** = Implementation location (file + symbol).
- **Integration** = callers/consumers of the symbol within the workspace.
- **Tests** = unit/integration tests that verify the requirement.
- **Docs** = documentation describing the behaviour.

All file paths are relative to the repository root (`/home/z/my-project/AlkALive`).
